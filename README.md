# Ovi Demetrian — Portfolio (PWA)

1. Create a public GitHub repo named `portfolio` and upload every file in this folder.
2. Settings → Pages → Deploy from branch → `main` / root.
3. Live at https://ovidemetrian.github.io/portfolio/ — open on the phone, "Add to Home screen" to install.
4. Room photos are `room-1.jpg` … `room-5.jpg`; replace any file with the same name to swap a photo.
5. After editing files, change `VERSION` in `sw.js` so phones pick up the update.
6. Paste the URL into LinkedIn: Featured → Add link. The square `og-image.png` is the preview card.
